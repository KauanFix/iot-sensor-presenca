## Enunciado: Lendo o Sensor de Presença!

O projeto vai utilizar um sensor PIR como entrada para acender um LED, no momento que o sensor detectar algum movimento, o LED se acenderá por um tempo

- O Arduino lê o estado do PIR pelo **pino 13**
- Acende o LED pelo **pino 2**

## Materiais necessários

| Qtd | Componente |
|-----|------------|
| 1 | Placa Arduino UNO |
| 1 | Cabo USB |
| 1 | Protoboard |
| 1 | Resistor de 220Ω |
| 1 | Sensor PIR |
| 1 | Luz LED Vermelha |
| — | Fios de jumper macho-macho |
